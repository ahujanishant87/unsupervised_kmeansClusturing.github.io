# Germany Stock clustering

## Project Aim:
The dataset used is german stock prices for back to back dates for differnt companies listed on german stock exchange. The aim is to check if we can achieves to find stocks which can be divided into distinct clusters based on their stock performance.

## Task:
1. Import the data
2. Cleanse the data and split the dataset into Xtrain and Xtest
3. Import Kmeans from sklearn.cluster
4. Find centroid using elbow method
5. Fit the model
6. Plot the Xtest to find clusters
7. Plot the performance metrics
